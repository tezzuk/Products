## STEP 2: Discovery Call Script

When someone responds with interest, ask these questions (WhatsApp is fine):

```
Great! Just 3 quick questions to understand what you need:

1. What's the most time-consuming repetitive task in your business right now?
2. Do you currently use anything (Excel, paper, WhatsApp) to manage it?
3. What would the ideal solution look like for you?
```

Their answers tell you exactly what to build.

## STEP 3: How to Build with Claude (on laptop)

Once you understand what they need, use this master prompt structure:

```
I need to build [specific tool] for a [type of business].

Requirements:
- [list what they told you]
- Should work in Google Sheets / Python (pick one)
- Must be simple enough for a non-technical person to use
- [any specific features]

Please build this completely. Include:
1. The full working code / formula setup
2. Step-by-step setup instructions I can send to the client
3. A simple user guide in plain language
```

Claude will produce a complete, working tool. You review it quickly, test it, then deliver.

## QUICK BUILD EXAMPLES

### Tool 1: Fee + Attendance Tracker (for tutors)
**Claude prompt:**
```
Build a Google Sheets template for a private tutor to track:
- Student names and monthly fees
- Daily attendance (present/absent)
- Payment status (paid/pending/partial)
- Auto-calculation of dues
- Color coding: green = paid, red = pending

Make it simple and beautiful. Include setup instructions.
```

### Tool 2: Daily Order Tracker (for home bakers / tiffin services)
**Claude prompt:**
```
Build a Google Sheets tool for a home baker to manage daily orders:
- Customer name, phone, order details, delivery date
- Payment status
- Daily summary (total orders, total revenue)
- A simple order form they can share via link (Google Forms linked to sheet)

Include setup instructions for a non-technical person.
```

### Tool 3: Auto Invoice Generator
**Claude prompt:**
```
Build a Google Sheets invoice generator:
- Business fills in: client name, services, amounts
- Sheet auto-calculates total with GST
- One-click to generate a printable/shareable invoice
- Saves invoice history in a separate tab

Keep it very simple. Include setup instructions.
```
