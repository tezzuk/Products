## 5. OBJECTION HANDLERS

**"Data kaise bhejun?"**
```
Koi bhi format kaam karta hai bhai — Tally se export karo, ya Excel mein date, item, amount wali simple list banao. WhatsApp pe hi bhej do.
```

**"₹999 zyada hai"**
```
Bhai ek accountant se ek din ki consultation ₹2000+ hoti hai. Ye ek baar ka ₹999 hai, aur report aapke paas hamesha rahegi. Agar value na mile toh paisa wapas.
```

**"Pehle sample dikhao"**
```
Bilkul — ye dekho [attach sample PDF]. Ye ek restaurant ka data tha. Aapki dukaan ka bhi aisa hi banega.
```

**"Baad mein"**
```
Koi baat nahi bhai. Ye number save kar lo — jab bhi ready ho, ping karna. Offer abhi same hai.
```

1. Search WhatsApp: "Kanpur traders", "Kanpur business", "Kanpur vyapari"
2. Ask any shopkeeper contact: "Koi business WhatsApp group ho toh add kar do"
3. Facebook: Search "Kanpur Vyapar Mandal" → most groups have WhatsApp link in description
4. JustDial/IndiaMART: Save numbers → add to WhatsApp → see if they're in groups
