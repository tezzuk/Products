# IndiaMART Cold Outreach — Script & Process

---

## HOW TO FIND NUMBERS ON INDIAMART

1. Go to **indiamart.com**
2. Search: "retail shop Kanpur" / "restaurant Kanpur" / "clothing store Kanpur" / "electronics Kanpur"
3. Every listing shows: Business name, location, phone number (sometimes hidden behind "View Number" — click it)
4. Export or manually note: Business name + phone number
5. Target businesses with 1–50 employees (small enough to not have an analyst)

**Other sources:**
- **JustDial:** justdial.com → search "retail shops Kanpur" → get numbers
- **Google Maps:** Search "restaurants near Kanpur" → every listing has phone + WhatsApp
- **Sulekha:** Similar to JustDial

**Target: 30 numbers per session. Takes ~1 hour to collect.**

## WHATSAPP MESSAGE (preferred — higher response than call)

**Step 1 — First message (no pitch yet, just curiosity hook):**

```
Hi [Name/Business Name], 

Aapka business IndiaMART pe dekha. Quick question — kya aap apna monthly sales data track karte hain Excel ya kisi software mein?
```

*(Wait for reply. This gets a much higher response rate than sending the full pitch immediately.)*

**Step 2 — After they reply "haan" / "yes" / anything:**

```
Great! Main small retail/restaurant businesses ke liye ek sales analysis report banata hoon — aap apna billing data bhejte ho, main 24 ghante mein ek full report de deta hoon:

📊 Kaunsa product sabse zyada chalta hai
📅 Week ka best/worst din
🤖 Agla mahina kaisa jayega (AI forecast)
📦 Kya restock karna chahiye

Sirf ₹999 — ek baar ka kaam. Sample dekho 👇
[attach screenshot of dashboard/report]

Interested?
```

## COLD CALL SCRIPT (if you want to call)

**Opening (first 10 seconds matter most):**

```
"Hello, [Name] ji? 

Main Aayushman bol raha hoon. Aapka [Shop Name] dekha — ek chhoti si baat karni thi, 2 minute milenge?"

[They say yes]

"Aapke paas apni dukaan ka pichle kuch mahino ka billing data hoga — Excel mein ya kisi software mein. Main wo data lekar ek report banata hoon jo batata hai — kaunsa item sabse zyada bikta hai, week ka best din kaun sa hai, agla mahina kaisa jayega.

₹999 mein. 24 ghante mein report WhatsApp pe.

Kya ye kaam ka lagta hai aapko?"
```

**If they say "kya hoga isse":**
```
"Ek example bataata hoon — ek restaurant tha, unhe pata hi nahi tha ki Sunday lunch unka sabse bada revenue time hai. Report ke baad unhone Sunday specials shuru kiya — 20% revenue badh gaya. 

Aapki dukaan ka data bhi aisa hi kuch batayega."
```

**If they say "sochta hoon":**
```
"Bilkul ji. Main aapko ek sample report WhatsApp kar deta hoon — dekh lena, agar kaam ka lage toh batana. Number note kar lein — [your number]."
```

**If they say "nahi chahiye":**
```
"Koi baat nahi ji. Agar kabhi zaroorat ho toh number save kar lena. Good day!"
[Move on. Never argue.]
```

## PAYMENT & DELIVERY PROCESS

1. Client agrees → ask them to send data on WhatsApp
2. Run the dashboard locally → export PDF report
3. Send PDF on WhatsApp
4. Send UPI payment request: `[your UPI ID]`
5. Confirm payment → done

**Keep it simple. No invoices, no formal process — WhatsApp pe data lena, WhatsApp pe report dena, WhatsApp pe payment lena.**
