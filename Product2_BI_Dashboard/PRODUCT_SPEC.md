# Product 2 — Business Intelligence Dashboard
*Last updated: 2026-06-09*

## What It Does
A live web dashboard that answers the 3 questions every business owner wants:
1. **"How much did I make today / this week / this month?"** — Revenue tracking
2. **"Which products are selling and which aren't?"** — Product performance
3. **"Who are my best customers?"** — Customer analytics

Works with whatever data the client has:
- Excel / Google Sheets → upload directly
- WhatsApp order messages → paste in, system parses them
- No data yet → built-in data entry form included

## Tech Stack
- **Streamlit** (Python) — builds beautiful dashboards fast, deploys free
- **Pandas** for data processing
- **Plotly** for charts
- **Deployed on Streamlit Cloud** (free, live URL in minutes)
- Claude builds everything

## Kanpur Target Customers

Need to track: daily sales per platform, which SKUs are selling, revenue by month

### Medical Stores / Pharmacies

## What the Dashboard Includes
| Section | What it shows |
|---|---|
| Revenue Overview | Today / This Week / This Month / vs Last Month |
| Top Products | Bar chart: best and worst sellers |
| Customer List | Who ordered most, total spend per customer |
| Daily Trend | Line chart of revenue over time |
| Alerts | "Stock running low" / "Revenue down 20% vs last week" |

## Data Input Options Built In
1. **CSV/Excel upload** — drag and drop
2. **Manual entry form** — fill in daily sales
3. **Google Sheets sync** — paste Sheet URL, auto-refreshes

## Edge Cases
- Client has messy/inconsistent data → Claude cleans it before dashboard builds
- Client adds new products later → dashboard auto-detects new entries
- Client loses the URL → they can bookmark it, it's a permanent link
